# Primeira Avaliação de Programação LACIS

# Provadatabase.py:

Nessa priemira etapa busquei alguns dos comando básicos de SQLite3, pra poder criar as funções que usei de fato no código, busquei compreender o fluxo, desde a criação do banco de dados até o encerramento da conexão com o mesmo, vi alguns comandos como .connect(), o .cursor() e o cursor.execute(), foi o primeiro contato "aprofundado" que tive com SQL e bancos de dados no geral, achei bem proveitoso e compreeendi bem essa etapa.

# Provamain.py: 

Nessa etapa utilizei o código main para usar as funções que criei nos outros códigos, de modo que o código do database foi requerido parar criar a tabela, e o código routes para realizar as outras funções que importei do código do database, nessa etapa consegui compreender melhor a necessidade de fragmentar o processo de desenvolvimento, principalmente pra recursividade de códigos secundários ao main.

# Routesprova.py:

Nesse código precisei utilizar IA para elaborar o front end, não tenho famiiaridade com as ferramentas e a sintaxe de front. Ele atua como intermediário entre o usuário e o database, lidando com as requisações e atualiações do banco de dados que foram feitas pelo usuário.
