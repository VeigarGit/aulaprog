Gerenciador de tarefas com banco de dados.


Estrutura do código:
gerenciador/
├── main.py         
├── database.py     
└── routes.py       

Pré-requisitos: Python3 instalado e um navegador.

Como rodar: inicie o main.py e abra http://localhost:8000
Site é interativo e bem simples de usar

bibliotecas utilizadas: http.server , sqlite3 , urllib.parse , datetime
frameworks: BOOTSTRAP

Codigo funcional e escalável
